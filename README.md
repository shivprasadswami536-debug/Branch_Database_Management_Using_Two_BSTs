# Branch_Database_Management_Using_Two_BSTs

Branch Database Management Using Two BSTs

Problem Statement

Develop a branch database management application using two Binary Search Trees (BSTs). Identify common keys and merge the records into a single BST.

Objective

- To manage branch records using BST.
- To find common keys in two BSTs.
- To merge records into a single BST.

Language

C++

Data Structure Used

Binary Search Tree (BST)

Features

- Insert branch records.
- Display records using traversal.
- Identify common keys.
- Merge two BSTs into one BST.

How to Run

1. Download or clone the repository.
2. Open the code in a C++ compiler.
3. Compile and run the program.

Conclusion

This project demonstrates how two BSTs can be used to manage branch records, find common keys, and merge records into a single BST.
